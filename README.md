# Conseal

Conseal is a full-stack PII anonymization review system for the SprintFour hackathon. This repository currently contains the Phase 0 scaffold for a Next.js frontend and FastAPI backend.

## Local development

Frontend command placeholder:

```bash
cd frontend
npm run dev
```

Backend command placeholder:

```bash
cd backend
uvicorn main:app --reload
```

Phase 0 scaffold is complete.
